# 密码の小本 (PasswordNotebook)

从 WiFi 密码生成器进化而来的全功能密码管理器。

## 功能

- **三种密码生成模式**
  - 哈希生成：基于核心词 + 年份-周数的 SHA-256 哈希密码
  - 周期密码：基于时间 + 自定义盐的定期轮换密码
  - 随机密码：可配置的随机密码生成器（含强度评估）

- **AES-256-GCM 加密存储**
  - 所有密码记录使用 AES-256-GCM 加密
  - 12 字节随机 IV，128 位 GCM Tag
  - 密钥基于 PBKDF2WithHmacSHA256 派生

- **符号类型拆分**
  - 常见符号：`!@#$%^&*-_=+.`
  - 扩展符号：`<>[]{}()/\`
  - 适应不同网站的密码规则限制

- **批量导入/导出**
  - 明文导出（Tab 分隔 TXT）
  - 加密导出（保持内部加密格式）
  - 自动识别加密格式导入
  - 重复名称自动跳过

- **矩阵代码雨背景**
  - 赛博朋克风格
  - 800~1600 px/s 高速下落

## 技术栈

- Java + Android SDK 35
- 纯代码 UI（无 XML 布局）
- API 21+ 兼容
- 零权限申请

